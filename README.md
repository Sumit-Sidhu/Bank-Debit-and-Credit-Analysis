## 📊 Project Overview

This project focuses on analyzing bank debit and credit transactions to understand transaction patterns, cash inflows, cash outflows, and overall financial activity.

The objective is to transform raw banking transaction data into meaningful insights through interactive dashboards and data visualization.

## 🎯 Project Objectives

* Analyze total debit and credit transactions.

* Monitor cash inflows and outflows.

* Identify monthly debit and credit trends.

* Understand transaction patterns and frequency.

* Evaluate account-wise transaction activities.

* Track net transaction balance.

* Support data-driven financial analysis.

## 📈 Dashboard Features

### 1. Debit and Credit Analysis

* Comparison of total debit and credit amounts.

* Analysis of transaction volumes.

* Identification of cash inflows and outflows.

### 2. Monthly Transaction Analysis

* Monthly debit and credit trends.

* Transaction activity over time.

* Identification of high-activity months.

### 3. Transaction Analysis

* Transaction type analysis.

* Account-wise transaction distribution.

* Debit and credit transaction patterns.

## 💡 Key Insights

* Compare money inflows against outflows.

* Identify monthly transaction trends.
